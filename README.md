# ConvLens

面向人工智能通识课程的卷积神经网络（CNN）可视化教学实验室。它把“数据 → 卷积 → 训练 → 推理”整合在一个浏览器页面中，适合课堂讲解和学生自主探索。

## 功能

- **训练工作台**：展示轻量 CNN 的网络结构、训练进度、准确率与验证集曲线；可以开始、暂停、继续和重置训练模拟。
- **本地数据导入**：选择 JPG/PNG 图片加入待标注数据集。图片只在浏览器本地使用，不会上传。
- **卷积透镜**：点击 5×5 输入图像移动 3×3 卷积核，实时查看逐元素乘法、求和、ReLU 激活及特征图输出。内置边缘检测、锐化、模糊三种卷积核。
- **模型体验**：上传图像后查看分类预测、类别置信度与模型关注区域示意。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开终端中显示的地址（通常为 `http://localhost:5173`）。

## 生产构建

```bash
npm run build
```

构建产物位于 `dist/`，可直接部署到 GitHub Pages、Netlify 或 Vercel。

## 教学说明

目前的训练指标和推理结果采用**可解释的前端教学模拟**，用来把 CNN 的关键机制清晰地呈现出来；它不是以用户上传图片实时训练的生产级模型。后续若需要接入 TensorFlow.js、Python/FastAPI 等真实训练后端，可在保持当前交互界面的前提下扩展。
